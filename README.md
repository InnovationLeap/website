# INNOVATION LEAP 官网

这是新版 INNOVATION LEAP 官网，使用 [bun](https://bun.com/) + [Astro](https://astro.build/) + [Tailwind CSS](https://tailwindcss.com/) 构建。

## 快速开始

### 安装依赖
```bash
bun install
```

### 开发环境
```bash
bun run dev
```

### 构建
```bash
bun run build
```

### 预览构建结果
```bash
bun run preview
```
